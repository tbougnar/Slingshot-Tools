## I. Final status

**BLOCKED — EXTERNAL REQUIREMENT PREVENTS COMPLETION:**

Every confirmed, actionable defect found by this audit has been fixed and independently verified: 31 of 33, with zero open.

The work that remains cannot be done from here, and the reason is now known exactly rather than guessed at. itch.io sits behind a Cloudflare Turnstile bot challenge: a headless browser is served a "Just a moment..." page with a single hidden cf-turnstile-response input instead of the login form. Getting past a bot check is evading an anti-abuse control, and this will not do that.

The API key is not part of this problem. butler authenticates with the key, and the key is confirmed working: butler reaches the itch.io builds endpoint with it and is refused only for a project that does not exist. No session cookie is needed for a release, and none should be pasted in.

What remains is one project that has to exist before anything can be uploaded to it, and itch.io offers no endpoint for creating one. The web login that would create it is the thing behind the bot challenge, and getting past a bot check is evading an anti-abuse control, which this will not do.

Everything up to that point is verified working. The pipeline runs green end to end: it generates a product, validates its javascript, scans it in a real browser, builds a Windows installer, uploads it as an artifact, and offers it to itch.io with a key that itch.io accepts.

To finish, the account holder creates one empty project by hand, once:

```
https://itch.io/settings/mine/new/game
```

then points the catalogue at it:

```
python set_itch_url.py <slug> https://slingshot-tools.itch.io/<project>
```

After that, dispatch `friday-build.yml`. The pipeline builds, uploads with the key, verifies the page answers, publishes the site and announces it, with no manual step and no credential that expires.

This is not a claim that no defect exists anywhere. It is a claim that every defect this audit found has a recorded cause, a fix or a documented blocker, and a test where one was practicable, and that the ones that mattered most were invisible to a green suite until the code was broken deliberately.
